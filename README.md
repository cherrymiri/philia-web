# PHILIA 재료 넣기·말랑이 섞기

기존 `PHILIA_objects.glb`를 그대로 사용하는 Three.js + Vite 프로젝트입니다.

## 실행

Node.js가 설치된 PC에서 이 폴더를 열고 실행합니다.

```
npm install
npm run dev
```

터미널에 표시되는 주소(보통 http://localhost:5173)를 브라우저로 엽니다. 같은 와이파이의 휴대폰에서는 `Network`로 표시되는 주소를 엽니다.

## 조작

- 유리컵 또는 이름을 누르면 파츠가 말랑이에 들어갑니다. 누를 때마다 추가됩니다.
- 세럼병 또는 이름을 누르면 스포이트가 말랑이 위로 옵니다. 말랑이를 누를 때마다 한 방울씩 떨어집니다.
- `넣기 완료` 또는 같은 세럼병을 누르면 스포이트가 돌아갑니다.
- 재료 하나를 넣는 동안에는 다른 재료를 선택할 수 없습니다.
- `처음부터 다시`는 내부 파츠, 색소, 저장된 기록을 모두 지웁니다. 파츠가 들어가는 중에는 작동하지 않습니다.

## 말랑이 섞기

- `말랑이 섞기`를 누르면 섞기 화면으로, `재료 더 넣기`를 누르면 재료 화면으로 돌아갑니다. 결과는 유지됩니다.
- 꾹 누르기: 말랑이 안쪽을 누르고 있습니다. 누른 채 움직이면 그 방향으로 재료가 밀립니다.
- 늘리기: 가장자리를 잡고 바깥으로 끕니다.
- 접기: 가장자리를 잡고 중앙으로 끕니다.

## 주요 파일

- `src/config.js`: 재료 문구·태그, 파츠 배율, 색소 색, 카메라 구도
- `src/naming.js`: 말랑이 이름 규칙
- `src/state.js`: 조합 기록
- `src/main.js`: 배치, 컵·스포이트 애니메이션, 모드 전환, 엔딩
- `src/input.js`: 마우스·터치 입력
- `src/hand.js`: 손 인식
- `src/save.js`: PNG 저장
- `src/mix/engine.js`: 공통 명령 `press`, `drag`, `stretch`, `fold`, `release`
- `src/mix/deform.js`: 말랑이 변형. 접기 계산은 여기 한 곳에만 있습니다.
- `src/mix/parts.js`: 파츠 이동·회전
- `src/mix/pigment.js`: 색소 번짐·혼합
- `src/gel.js`: 말랑이 재질, 내부 높이 계산

## 손 인식

- HTTPS 또는 localhost에서만 작동합니다.
- 모델은 처음 켤 때 Google 저장소에서 내려받습니다. 인터넷이 불안정한 전시장에서는 `hand_landmarker.task`를 `public/models/`에 넣으면 그 파일을 먼저 사용합니다.
- 카메라 영상은 브라우저 안에서만 처리하며 저장하거나 전송하지 않습니다.

## 화면 글꼴

`src/PretendardSubset.woff2`는 화면 문구에 쓰인 글자만 담고 있습니다. 문구를 바꾸면 없는 글자는 기본 글꼴로 나오니 글꼴을 다시 추려야 합니다.

## 저장 데이터

`philia.mix.v1`, `philia.field.v1`(색소 상태), `philia.plastic.v1`(말랑이에 남은 변형) (localStorage). 개발자 도구에서 `PHILIA.state()`, `PHILIA.summary()`로 볼 수 있습니다.

- `parts`: 종류, 위치, 회전(쿼터니언), 배율, 투입 순서. 반짝이는 한 줌을 1개 기록으로 저장하고 `particles`에 각 입자 위치를 담습니다.
- `pigments`: 색소 종류, 위치, 투입 순서
- `sequence`: 재료를 선택한 순서
- `summary()`: 파츠별 수량, 색소별 투입 횟수, 재료별 의미와 태그

위치는 말랑이 기준 좌표(미터)입니다.

## 테스트용 주소 옵션

`?maxfps=1`, `?speed=4`, `?norender`는 저사양 자동 테스트용입니다. 일반 사용에는 필요 없습니다.
